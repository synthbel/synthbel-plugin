# Comparing a correction with a protected method

Use this procedure when a list, crosswise, randomized-response or other indirect result is available for assessing a proposed F correction. Agreement is an observable target even when the protected result is not a verified measure of private belief.

1. Define the comparable construct, period, population and denominator before selecting cases. Recover routing and original answer codes. Keep historical or task-changing comparisons separate from contemporary randomized direct/protected designs. Record unavailable cases and source discrepancies before predictions.
2. Build a prediction input excluding protected responses, estimates, intervals, corrected totals and all target-derived gaps or interpretations. Methods notes, summaries and prior model discussions can reveal the target. Use a fresh prediction context, preserve the exact supplied instructions and evidence, and record remaining shared context and possible pretrained familiarity.
3. Freeze the case set, inputs, model/settings, repeats, comparison references, distance metric and simple comparison rules chosen without the protected target. Include no adjustment and a substantively plausible fixed-shift or directional rule to assess whether the model adds discrimination. Obtain central full-category corrections and alternatives; save every output before scoring. Keep invalid outputs and refusals. Later discoveries are new evidence for a subsequent variant, not retroactive inputs.
4. Compare absolute focal-share distance before and after correction for every case and every declared reference. Positive `abs(observed-reference) - abs(corrected-reference)` means closer. Show all repeats and the frozen simple alternatives. A large initial direct/protected gap can make many same-direction shifts closer, so report how discriminating that improvement is and whether the model beats the simple rules. Later-added comparisons are exploratory. Repeated historical baselines evaluated against one protected estimate do not create independent experiments.
5. Retain published and transparently reproduced estimates separately. Show how processing, weights, cleaning, impossible estimates and design diagnostics change conclusions. A failed protected-measurement assumption qualifies the comparison; it is not a reason to hide an inconvenient result or select a reference that favors the model.

The output is complete when the reader can see where the correction helps, where it hurts, whether additional evidence helps, and which conclusions depend on the chosen reference. Numerical agreement does not by itself identify a fear mechanism. A comparison using later publications remains retrospective even when the supplied target results were hidden.
